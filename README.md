# Cicero — Reply Master

Pre-written customer replies, one click to copy — with the customer's
name filled in for you. Groups, a grid view, a full emoji picker, and
optional sync through your own Google Drive so your replies follow
you between computers (nothing is ever stored on our side).

A [Tool Smithy](https://www.patreon.com/c/ToolSmithy) app by Jazza
Studios — Tool Smithy exists to share free, useful tools.

## Download

Grab the latest `Cicero_x.y.z_x64-setup.exe` from
[Releases](https://github.com/ToolSmithy/cicero/releases/latest) and
run it. Cicero checks this page for updates on launch and offers them
in-app — install once, stay current.

## Notes for testers

- Windows 10/11, x64.
- Your data lives in `%APPDATA%\com.toolsmithy.cicero\` — deleting
  that folder is a factory reset.
- Google sign-in is currently in testing mode: only invited test
  accounts can use sync. Everything else works without signing in.
